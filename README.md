# Formação em Engenharia de Dados e Business Intelligence

Este repositório reúne os projetos práticos e desafios de modelagem dimensional e visualização de dados desenvolvidos ao longo do curso. O foco das atividades envolve o processamento de dados brutos (ETL), estruturação de bancos de dados relacionais e criação de dashboards gerenciais para tomada de decisões.

## Desafios Desenvolvidos

Abaixo está a listagem detalhada de cada projeto entregue, contendo suas respectivas especificações técnicas e links de acesso:

### 1. Miniguia de Estudos Inteligente (NotebookLM)
*   **Descrição:** Caderno de estudos focado na evolução dos suportes de leitura, do livro físico ao digital. O projeto explora engenharia de prompts avançada para consolidar resumos e glossários a partir de fontes de dados abertas.
*   **Link do Projeto:** [(https://github.com/carolhr/-miniguia-estudos-notebooklm-a-evolu-o-dos-livros)

### 2. Relatório de Modelagem Financeira Basilar
*   **Descrição:** Primeira etapa de extração e estruturação visual de dados financeiros analíticos. Consolida métricas iniciais de performance organizacional em formato executivo.
*   **Link do Projeto:** [Myfinacial.pdf](https://github.com/carolhr/MYpower_bi_analyst/blob/main/minhapasta/Myfinacial.pdf)

### 3. Análise de Vendas e Desempenho Comercial (Desafio 3)
*   **Descrição:** Relatório analítico avançado focado na performance de vendas ("sales"), segmentação de mercado e acompanhamento de metas comerciais.
*   **Link do Projeto:** [sales-desafio3.pdf](https://github.com/carolhr/MYpower_bi_analyst/blob/main/minhapasta/sales-desafio3.pdf)

### 4. Modelo Dimensional de Instituição de Ensino (Star Schema)
*   **Descrição:** Criação de um ambiente de Data Warehouse estruturado do zero no MySQL focado no corpo docente. Inclui o desenvolvimento de chaves substitutas (Surrogate Keys) e uma tabela dimensão de tempo dedicada.
*   **Link do Projeto:** [Star_Schema](https://github.com/carolhr/Star_Schema)

### 5. Otimização de Arquitetura Financeira (Finance Star Schema)
*   **Descrição:** Processo de ETL avançado que transforma uma base única de dados flat ("financials") em uma modelagem em estrela limpa, com tabelas de fatos e dimensões interligadas via DAX e Power Query.
*   **Link do Projeto:** [Finance_Star_Schema](https://github.com/carolhr/Finance_Star_Schema)

### 6. Dashboard Executivo de Relatório de Vendas Comercial
*   **Descrição:** Painel visual completo desenvolvido sob boas práticas de UI/UX utilizando tema escuro, focado na exibição de faturamento integral e análise geográfica de lucratividade por país.
*   **Link do Projeto:** [Relatório_vendas.pdf](https://github.com/carolhr/MYpower_bi_analyst/blob/main/minhapasta/Relat%C3%B3rio_vendas.pdf)

## Tecnologias e Ferramentas Aplicadas

*   Microsoft Power BI & Power Query (M)
*   Banco de Dados MySQL & Workbench
*   Linguagem DAX (Inteligência de Tempo)
*   Google NotebookLM
*   Modelagem Dimensional (Fatos e Dimensões)
